Plugin Settings

Stored locally in the extension (chrome.storage.local)

General

Queues

Every pull is scoped to these assignment groups by name. Names must match the group's display name in ServiceNow. Type a name and press Enter — paste several separated by commas or new lines.

Team members

Used ONLY to detect acknowledgement dates (when a ticket gets assigned to one of these people). Names must match how ServiceNow displays the user. Type a name and press Enter — paste several separated by commas or new lines. Leave empty to skip acknowledgement detection.

Pull parameters

Rows per Table API page during pulls (100–5000, default 1000).
How long a pulled ticket list is reused without re-fetching (0–10080, default 15). A pull re-uses cached results only if the same query ran within this window; 0 disables caching so every pull hits the API. Timeline cache is unaffected.
Safety cap: if a filter matches MORE tickets than this, the set is skipped and you are warned instead of pulling (0–100000, default 500; 0 = unlimited). Preview shows the same warning before you run.
Adds a truncated body preview and row count for every API call to the log. Verbose — enable only while troubleshooting.
Query results are reused for 15 min; timelines until the ticket changes (max 7 days).

MSR option lists

Allowed values for the MSR report dropdown columns (BA AO sheet). The data view restricts these columns to the lists below, and exports/copy-for-MSR use exactly these labels. One value per chip — type and press Enter, or paste several separated by commas/new lines. Emptying a list falls back to nothing — use "Restore defaults" for the original msr.xlsx values.
The RFS root-cause list is empty in the source msr.xlsx — add values here if you raise RFS tickets.

Backup / transfer

Exports one JSON file with instance URL, queues, team members, pull params, saved filters, column mapping, CI split groups, hidden view columns, MSR option lists and the cached Excel template. Import replaces all of those with the file's values.
