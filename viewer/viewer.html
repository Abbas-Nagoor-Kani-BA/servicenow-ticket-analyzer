Export column mapping

Pick the Excel column (A–AN) each field is written to. A field exports to one column; unmapped fields are skipped and unmapped columns stay as the template has them.

Split export by configuration item

Groups become the file names. Drag configuration items between groups. An item matches every configuration item that contains it (anywhere in the name) — e.g. "Payment Gateway" also matches "Payment Gateway PRD / PreLive / DEV / TEST" and "Web Payment Gateway". Longest match wins; the rest go to Others. Add one item per box, or paste/type several separated by commas or new lines.
